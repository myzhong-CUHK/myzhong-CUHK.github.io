# Problem.

Eleven pirates put their loot in a safe and agree that any majority of them, meaning any six or more, should be able to open it, while no five of them should. A locksmith puts a number of locks on the safe, all of which must be opened. Each lock may have several keys, each key opens exactly one lock, and a pirate may carry several keys. What is the smallest number of locks, what is the smallest number of keys, and how many keys does each pirate end up carrying?

# Solution.

Write $P$ for the set of eleven pirates.

**A lock is completely described by who can open it.** The only thing ever asked of a lock $L$ is which pirates hold one of its keys, so write $H(L) \subseteq P$ for that set of key **h**olders. Two locks with the same $H$ are interchangeable, and a locking scheme is therefore nothing more than a list of subsets of $P$, one per lock.

**A group opens a lock when it contains a key holder.** A group $T$ can open $L$ precisely when at least one pirate of $T$ holds a key to it, i.e., $T \cap H(L) \neq \emptyset$. The safe demands that every lock be opened, so $T$ opens the safe exactly when this holds for all locks simultaneously.

The two rules of the pirates now read as follows.

- Any six of them open the safe, so every six-element set $T$ meets every $H(L)$.
- No five of them do, so every five-element set $S$ must have some lock it misses entirely.

### The number of locks is at least $\binom{11}{5}$

Fix a five-element set $S$. Since $S$ must fail, some lock $L_S$ has $S \cap H(L_S) = \emptyset$.

These locks are distinct for distinct $S$. The map $S \mapsto L_S$ is therefore injective, and the number of locks is at least

$$
\binom{11}{5} = 462.
$$

### Each of those locks needs at least six keys

Every pirate outside $S$ holds a key to $L_S$, giving $|H(L_S)| = 6$ and a total of at least $462 \times 6 = 2772$ keys.

### How many keys each pirate carries

Pirate $p$ holds a key to $L_S$ exactly when $p \notin S$. So counting the keys of $p$ is counting the five-element sets that avoid $p$, and such a set is chosen freely from the other ten pirates:

$$
\#\{\text{keys of } p\} = \binom{10}{5} = 252 .
$$


### General $n$ and $m$

For $n$ pirates with any $m$ of them allowed to open the safe, the same argument applied to the $(m-1)$-element sets gives

$$
\text{locks} = \binom{n}{m-1}, \qquad \text{keys} = (n-m+1)\binom{n}{m-1}, \qquad \text{keys per pirate} = \binom{n-1}{m-1}.
$$
